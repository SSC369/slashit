# Sub-plan 4.4 — Full erase

> **Approved** by @user on 2026-09-27. Locked — changes require a change record (§7).

Parent: [Implementation plan index](./04-implementation-plan.md) ·
Context: [PRD](./01-prd.md) FR-22, FR-23 · [Build plan](./03-build-plan.md) AD-2

## Tables touched

`memories` and `capture_turns`: rows deleted on forget instead of kept blank.
Migration `0030_forget_deletes` removes the traces earlier forgets left.

## 1. What works when this lands

Forgetting a memory deletes its row and every capture turn of its thread. No
placeholder is left in history. The confirmed `/forget` turn still reads
"Forgot 1 memory" or the count, with no words.

## 2. Requirements covered

| FR / NFR | How |
|---|---|
| FR-22 | `delete_memories` replaces `tombstone_memories` |
| FR-23 | `delete_turns_for_memories` replaces `scrub_turns_for_memories`, same thread rule (D-19) |
| NFR-2 | Rows gone, so no store holds the text |
