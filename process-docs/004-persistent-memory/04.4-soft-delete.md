## 1. What works when this lands

Forgetting a memory hides it and its capture-history words exactly as today,
but the row keeps its text, input, category and vector, and the turns keep
their words. No API the user can call returns a forgotten memory or its words.

## 6. Error handling

| Failure | Detected by | User sees | System does |
|---|---|---|---|
| Hide succeeds, forget fails | Exception after the port call | 001's inline error; memory still listed | A retry finds turns already hidden, a no-op. Same as 4.2 §5 |
| A new read path omits `deleted_at IS NULL` | C-4.2, C-4.7 | Nothing, if caught | The test fails the build. The constraint that used to back this up is gone |
| Downgrade with soft-forgotten text present | `0030` downgrade | n/a | Raises; nothing erased |
