# Sub-plan 4.1 — Save and browse

Context: [Index](./04-implementation-plan.md) · [PRD](./01-prd.md) ·
[Design](./02-design.md) · [Build plan](./03-build-plan.md)

Tables: `memories` new (`0024`); `capture_turns`, `pending_captures` changed
(`0025`); `ai_usage` changed (`0026`); `events` changed (`0027`); extension
`vector` (`0023`). Details in the [index](./04-implementation-plan.md).

## 1. What works when this lands

A signed-in user types `/remember My passport expires in 2030` or `/add-memory`
and sees the saved card with a category. `/memories` lists every memory and
`/memories career` finds by word. Records shows a Memories tab with category
chips, memory rows in All, a detail page and an edit form. A fact that looks
like a card number saves with the caution. With the model down, the save is
refused and the text kept. There is no conflict check yet, so this slice ships
only with slice 2.

## 5. Internal contracts

```python
# memories/services/memory_service.py
async def save_memory(self, *, user_id: UUID, text: str, original_input: str) -> SaveOutcome:
    # 1. len(text) > MAX_FACT_LENGTH -> MemoryTooLong (checked in capture first)
    # 2. secret = secret_check.detect(text=text)
    # 3. embedding = await embedding_port.embed(user_id=user_id, text=text); failure -> return it
    # 4. judgement = await judgement_port.judge(user_id=user_id, text=text, candidates=[])
    #    failure -> return it. Slice 2 fills candidates.
    # 5. insert memory with category, embedding; record memory_saved event
    #    (+ memory_secret_caution if secret); return MemorySavedDTO
```

Nothing is written before step 5, so a failure at 3 or 4 leaves no row (FR-9).

`keyword_query.build(text)` lowercases, splits on non-letters, drops
`PRODUCT_STOP_WORDS` (`remember`, `memory`, `memories`, `know`, `told`,
`recall`), and returns terms for `to_tsquery('english', 't1 | t2')`. Ranking is
`ts_rank`, then `created_at DESC`. Empty terms return no rows and the "No
memories match" card.

## 6. Error handling

| Case | Result | Where drawn |
|---|---|---|
| Argument empty | Pending question, `fact` | `CaptureStates`, FR-3 |
| Argument over 500 | `MemoryTooLong { length, limit }`, text kept | `CaptureStates`, FR-4 |
| Gateway failure, embed or generate | Failure member unmapped; `refused` turn | `CaptureStates`, FR-9 |
| Judgement returns an unknown category | Saved uncategorised | FR-6 |
| `memory(id)` for another user or unknown | `MemoryNotFound` | 001's not-found |
| `updateMemory` over 500 | `MemoryTooLong` | `MemoryEdit` counter |
| Reembed fails three times | `embedding` stays NULL, error logged by id | none, not user-visible |
