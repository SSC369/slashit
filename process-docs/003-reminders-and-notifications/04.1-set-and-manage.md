## 1. What works when this lands

A user types `/remind Call Mom tomorrow at 7pm` and gets a confirmation card and
a success toast reading the time in their own timezone; `/reminders` lists what
is set. The Reminders tab, the All tab, detail, edit and delete all work, with
every state drawn on canvas pages 1, 2, 7 and 8. Nothing fires yet; that is
slice 2.

## 5. Internal contracts

```python
# The model's output. It never returns a timestamp (build plan §5).
REMINDER_EXTRACTION_SCHEMA = {"type": "object", "required": ["description"], "properties": {
  "description": {"type": "string"},
  "local_date": {"type": "string"},          # YYYY-MM-DD, omitted if no date implied
  "local_time": {"type": "string"},          # HH:MM 24h, omitted if no time implied
  "repeat_kind": {"enum": ["none", "daily", "weekly", "monthly", "yearly"]},
  "repeat_interval": {"type": "integer"},
  "repeat_weekdays": {"type": "array", "items": {"type": "integer"}},
}}

class ReminderPort(Protocol):           # capture's words
    async def create_reminder(self, *, user_id: UUID, fields: ReminderFields, original_input: str) -> ReminderDTO | ReminderLimitReached: ...
    async def list_active(self, *, user_id: UUID) -> list[ReminderDTO]: ...

class LocalClockPort(Protocol):         # AD-7, used by every extraction
    async def local_now(self, *, user_id: UUID) -> tuple[datetime, str]: ...   # aware local now, IANA name
```

Validation in `update_reminder`, each raising a paired error: empty description;
`WEEKLY` with no weekdays; interval below 1 or above 99; a one-time instant not
after now (`ReminderEditPast`). Series edits recompute `next_fire_at` from now.

## 6. Error handling

| Failure | Detected by | User sees | System does |
|---|---|---|---|
| Model unavailable or quota spent | Gateway failure member | `RemindModelDown`: nothing saved, input kept | Records the turn as refused |
| No date in the text | Missing `local_date` | One question (`RemindAsk`) | Stores a pending capture, `remind_at` |
| Cap reached | Active count is 100 | `RemindAsk` refusal, input kept | Nothing written |
| Unknown or another user's id | Repository returns none | `ReminderNotFound` | Same response for both (NFR-6) |
| Invalid edit | Interactor validation | Field errors (`ReminderEditInvalid`, `ReminderEditPast`) | Nothing written |
| Deleted while editing | Update finds `deleted_at` set | `ReminderEditGone` | Nothing written |
| Save or delete fails | Network or 5xx | `ReminderEditFailed`, `DeleteReminderFailed` | Store unchanged; retry offered |
| Offline | `navigator.onLine` false | `RemindersOffline` | Mutations disabled |
| Session ended | 401 from the endpoint | `RemindersSessionEnded` | 002's sign-in route |
