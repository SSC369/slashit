Migration in this slice: `0019_firings_and_notifications`. New `reminder_firings`, `notifications`, `notification_deliveries`; changed `reminders`, one column `snoozed_until`, new to the index (see its change log).

## 1. What works when this lands

A reminder fires within a minute of its time. The bell counts it, the panel
lists it newest first, and an open app pops it up in the corner unless pop-ups
are off. Done, Snooze and Open work from the pop-up, the panel and the
Reminders tab. A reminder that fires up to a day late is marked Late; later
than that it is marked Missed. No email yet; that is slice 3.

## 5. Firing, step by step

```text
reminders.fire_due        periodic, every minute, service-role session
  due_at = LEAST(next_fire_at, snoozed_until)   # LEAST ignores NULL
  SELECT id, due_at FROM reminders
    WHERE deleted_at IS NULL AND state <> 'done' AND due_at <= now()
  for each: defer reminders.fire_one(reminder_id, scheduled_for=due_at),
            queueing_lock "fire:{reminder_id}:{scheduled_for}"

reminders.fire_one        one transaction, service-role session
  lock the reminder row FOR UPDATE
  stop if deleted, done, or due_at no longer equals scheduled_for (edited since)
  is_snooze = scheduled_for == snoozed_until
  recurring, not snooze: collapse to the latest occurrence <= now (AD-11)
  lateness = on_time <= 5 min < late <= 24 h < missed
  INSERT reminder_firings ... ON CONFLICT (reminder_id, scheduled_for) DO NOTHING
  stop if nothing inserted                               # AD-3
  notifications.publish(kind=reminder, source_id=firing.id, marker=lateness)
    INSERT notifications ... ON CONFLICT DO NOTHING
    INSERT notification_deliveries (channel=popup, status=sent|skipped)
    NOTIFY slashit_notifications '{"user_id":..., "notification_id":...}'
  update the reminder:
    state = fired; last_fired_at = scheduled_for
    snooze:     snoozed_until = NULL; next_fire_at unchanged
    one-time:   next_fire_at = NULL
    recurring:  next_fire_at = next_occurrence(after=max(now, scheduled_for))   # FR-24
  COMMIT                                                 # NOTIFY leaves here
  log reminder.fired: reminder_id, lateness, delay_ms    # never the text (T6)
```

| Action | One-time | Recurring |
|---|---|---|
| Done | `state = done`, `next_fire_at = NULL`, `snoozed_until = NULL` | `state = upcoming`, schedule unchanged |
| Snooze | `state = upcoming`, `snoozed_until` = chosen instant | Same; the series keeps its `next_fire_at` |

Both write `action` and `acted_at` on the latest firing and set `last_action`. Tomorrow is tomorrow in the reminder's zone at `default_reminder_time`.

## 7. Internal contracts

```python
class NotificationPort(Protocol):        # reminders' words
    async def announce_firing(self, *, user_id: UUID, firing_id: UUID,
                              reminder_id: UUID, title: str, detail: str,
                              lateness: Lateness) -> None: ...

class DeliverySettingsPort(Protocol):    # notifications' words
    async def popups_enabled(self, *, user_id: UUID) -> bool: ...

class SnoozeOption(StrEnum): TEN_MINUTES, ONE_HOUR, TOMORROW
```

```graphql
type Notification { id: ID!  kind: NotificationKind!  reminderId: ID  title: String!
  detail: String!  marker: NotificationMarker!  createdAt: DateTime!  read: Boolean!
  showPopup: Boolean! }
type NotificationPage { items: [Notification!]!  nextCursor: String }
markReminderDone(id: ID!): ReminderActionResult!          # Reminder | ReminderNotFound
snoozeReminder(id: ID!, option: SnoozeOption!): ReminderActionResult!
markNotificationRead(id: ID!): MarkReadResult!            # Notification | NotificationNotFound
type Subscription { notificationReceived: Notification! }
```

`showPopup` is the pop-up delivery's status at firing; the client never reads settings to decide.

## 8. Error handling

| Failure | Detected by | User sees | System does |
|---|---|---|---|
| Worker or sweep down | Reconciliation, slice 4 | Late or Missed marker when it recovers | One notice per reminder, never a flood (AD-11) |
| `fire_one` fails mid-way | Exception in the job | Nothing yet | Transaction rolls back; Procrastinate retries; the unique firing makes the retry safe |
| Reminder edited or deleted after its job was queued | `due_at` differs, or `deleted_at` set | Nothing fires | Job ends as a no-op, logged `reminder.fire_skipped` |
| `LISTEN` connection lost | Listener error | No pop-up until it returns | Reconnects with backoff; the client refetches list and count on WebSocket reconnect |
| Done or Snooze fails | Network or 5xx | `PopupFailed`, `PanelActionFailed` | Store unchanged; card stays; retry offered |
| Another user's or missing id | Repository returns none | `ReminderNotFound` / `NotificationNotFound` | Same answer for both (NFR-6) |
| Offline | `navigator.onLine` false | `PopupOffline`: Done and Snooze disabled, Open works | No mutation sent |
| Notifications fail to load | Query error | `NotificationStates` error: Try again | Bell keeps its last count |
| Session ends while subscribed | Socket closed on auth | Session card on next page load | Client reconnects with a fresh token, or signs out |
