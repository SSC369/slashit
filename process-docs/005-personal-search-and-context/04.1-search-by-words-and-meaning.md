## 1. What works when this lands

A signed-in user types `/search passport` and sees one card with Memories,
Tasks and Reminders groups, best match first, at most five per group with
"See all n in Records". `/search career` finds "Become a backend engineer"
with no shared word. `/search` alone asks what to search for; over 500
characters is refused with the text kept; nothing found says so. With the
meaning call down, word matches show with the amber line. History lists the
search with Run again. Every task and reminder, old or new, is searchable by
meaning. No question gets a written answer yet.

## 5. Contracts inside this slice

```python
# search/interfaces/ports.py
class QueryEmbeddingPort(Protocol):
    async def embed_query(self, *, user_id: UUID, text: str) -> tuple[float, ...] | None: ...
    # None on timeout, provider error or quota: the caller sets meaning_unavailable

# records/interfaces/ports.py  (reminders: the same, named for reminders)
class EmbedQueue(Protocol):
    async def queue_embed(self, *, user_id: UUID, record_id: UUID) -> None: ...
```

Port SQL, tasks shown, reminders and memories the same over their columns:

```sql
SELECT t.*, ts_rank(t.search_vector, :any_q)            AS word_rank,
       t.search_vector @@ :all_q                         AS all_terms,
       t.embedding <=> :vec                              AS distance
FROM tasks t
WHERE t.user_id = :uid AND t.deleted_at IS NULL
  AND (t.search_vector @@ :any_q OR t.embedding <=> :vec < :max_distance)
ORDER BY all_terms DESC, word_rank DESC, distance ASC
LIMIT :limit
```

`:any_q` is the terms OR-ed, `:all_q` AND-ed, both from `to_tsquery('english')`
over letters and digits only. The word pass calls it with no vector, so the
distance clause is dropped. The meaning pass calls it with the vector and no
terms. Search merges the two by record id, keeping word fields from the first
and distance from the second. `total` is the combined `WHERE` under
`count(*)`, run alongside the meaning pass, or with the word pass alone when
there is no vector.

Time: the embed (at most 2.5 s) overlaps the word pass, so a search costs the
slower of the two plus one meaning pass, about 2.8 s at today's measured embed,
`estimate`, inside NFR-3's 3 s.

## 6. Error handling

| Failure | Result |
|---|---|
| Embed timeout, provider error, quota | Words only, `meaningUnavailable: true` (FR-20). Logged with stage timing, no text |
| One port raises | The whole search fails with 001's "Something went wrong" capture error; nothing is written but the turn |
| Embed job fails three times | Row keeps `embedding` NULL; the periodic backfill retries within 10 minutes |
| Queue down after a save | Logged, swallowed; the save stands (004 P-6) |
| Backfill hits a provider limit | Stops the run and logs the count; the next periodic run continues |
